# Contributing

Contributions are welcome through GitHub Issue Forms.

Before contributing, please read:

- Website contribution guide: `contribute.qmd`
- Code of conduct: `CODE_OF_CONDUCT.md`

## What to contribute

Useful contributions include:

- papers, reports or articles for the materials section
- local resources, tools or support routes
- training ideas, case examples or clinic scenarios
- corrections, concerns or suggestions about existing pages

## How to contribute

1. Open the most relevant GitHub Issue Form.
2. Explain what you are suggesting and why it matters.
3. Include a DOI for papers where possible, or a stable URL/source for websites, tools and reports.
4. Be explicit about uncertainty, limits or conflicts of interest.

Please do not include confidential, sensitive or identifiable data in issues.
